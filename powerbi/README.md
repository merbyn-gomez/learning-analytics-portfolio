# Power BI | Learning Analytics Overview

**Editable Power BI Project (PBIP)** with a star-like relational semantic model, DAX measures and an executive report page.

## Open in Power BI Desktop (Windows)

1. Clone or download this repository. Keep the entire folder structure unchanged.
2. Open **powerbi/LearningAnalytics.pbip** in an up-to-date version of **Power BI Desktop**.
3. If prompted for credentials for **raw.githubusercontent.com**, choose **Anonymous** access (the sample CSVs are public).
4. Click **Home → Refresh** to import the synthetic CSV snapshot from \`powerbi/sample-data/\` hosted in this public GitHub repository.
5. Optional: **File → Save as** to save a local \`.pbix\` version.

> **Important:** This PBIP was generated programmatically. The JSON is syntactically valid, but the native project has **not been opened in Power BI Desktop in this environment**. If Desktop reports a PBIR/TMDL compatibility warning, consult the manual fallback below. No .pbix is claimed to be included.

## Model relationships

| From (many) | To (one) |
| --- | --- |
| Enrollments[student_id] | Students[student_id] |
| Enrollments[course_id] | Courses[course_id] |
| Activities[enrollment_id] | Enrollments[enrollment_id] |
| Assessments[enrollment_id] | Enrollments[enrollment_id] |

All relationship filter directions follow the dimension-to-fact pattern. Avoid changing them to bidirectional without a specific analysis need.

### Metric dictionary

| Metric | DAX logic |
| --- | --- |
| Completion rate | Completed enrollments ÷ all enrollments, including withdrawals |
| Unique learners | Distinct enrolled student IDs (not all registry students) |
| Learning hours | Sum of activity minutes ÷ 60 |
| Average final score | Mean score from completed enrollments only |
| Final pass rate | Completed-enrollment assessments with score ≥70 ÷ completed-enrollment assessments |
| Active enrollments 30D | Distinct enrollments with activity between 2–31 October 2026, inclusive |

The reporting snapshot is **fictional** and dated **31 October 2026**. It is not an actual LMS export or a model of real student outcomes. The fixed 30-day window is intended for demonstration only.

## Source and reproducibility

- The committed \`sample-data/*.csv\` is a frozen, independently generated *synthetic* Power BI fixture; it has the **same conceptual entities** as the Python/SQLite demonstration but is not the same random dataset.
- Power BI imports that snapshot via version-controlled M queries stored in \`LearningAnalytics.SemanticModel/definition/tables/\`.
- If you want to analyze the data generated by the Python pipeline instead, export its five SQLite tables to CSV with matching headers and switch the M queries to local \`File.Contents(...)\` sources.
- \`LearningAnalytics.SemanticModel/definition/tables/_Measures.tmdl\` contains the DAX definitions.
- The source model and report are textual and suitable for code review and Git version control.

## Manual fallback if PBIP cannot be opened

Open a new Power BI Desktop report and use **Get Data → Text/CSV** for each of the five files in \`sample-data/\`. Use **Transform Data** to assign integer types to ID and minutes/score columns; dates to date type; and labels to text. Create the relationships above in Model view. Paste the formulas from \`_Measures.tmdl\` as **New measure** and recreate the visuals listed above. Save as \`LearningAnalytics.pbix\`.
